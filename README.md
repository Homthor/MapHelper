# MapHelper — Интерактивный тренажёр экзаменационных маршрутов ГИБДД 🚗🎓

**MapHelper** — это веб-приложение для курсантов автошкол и автоинструкторов, предназначенное для детального изучения, разметки и анализа сложных экзаменационных маршрутов ГИБДД в любом городе России.

Сервис позволяет визуализировать дорожную разметку высокой чёткости (HD-разметка Яндекс Карт 3.0), раскладывать перекрёстки по отдельным полосам, отмечать ловушки инспекторов, безопасные траектории разворотов, разрешённые места остановок, а также сверяться с уличными панорамами 360° и свежими дорожными знаками.

---

## 🎯 Для чего предназначен сервис
Сдача практического экзамена в ГИБДД по городу требует идеального знания геометрии перекрёстков, требований дорожной разметки и знаков, которые часто стираются или закрываются деревьями.
**MapHelper решает главные боли курсантов:**
1. **Запоминание «правильных» полос:** заранее разметить, по какой полосе безопасно двигаться прямо, где образуется обязательный поворот только направо/налево, и в какой момент необходимо перестроиться.
2. **Сложные развороты:** наглядно построить безопасную дугу разворота на перекрёстке или с использованием прилегающей территории.
3. **Ловушки инспекторов и запреты:** отметить места, где часто звучат провокационные команды инспектора («найдите место для разворота», «выполните остановку»), где действуют неочевидные знаки ограничений или сплошные линии.
4. **Самопроверка по памяти:** скрыть цветовую разметку одним кликом и проверить себя перед реальным выездом на маршрут.
5. **Обмен опытом:** сохранить готовый разобранный маршрут в `.json` и передать одногруппникам или ученикам.

## 🛠️ Инструменты и возможности

### 🏙️ Выбор любого города России
- **Умный геокодер (OSM Nominatim):** введите название любого населённого пункта России (например, *Казань, Новосибирск, Смоленск, Краснодар*), и карта плавно переместится в центр города.
- **Быстрые пресеты:** популярные города доступны в один клик прямо из выпадающего списка.

### 🛣️ Векторная HD-разметка Яндекс Карт 3.0 (`vmap3`)
- Официальный векторный движок Яндекс Карт нового поколения с контекстом `future-map`.
- **Максимальная дорожная детализация:** на крупном масштабе отображаются полосы движения, направляющие стрелки на асфальте, островки безопасности, стоп-линии и пешеходные переходы.
- **Очистка от визуального мусора:** специализированный фильтр отключает коммерческие POI-точки (магазины, кафе, ТЦ, АЗС, банкоматы), оставляя карту чистой и сфокусированной на дорожной инфраструктуре.
- **Поддержка альтернативных слоёв:** возможность переключения на растровую Схему, чистый Спутник или Гибрид.

### 🚗 Конструктор многополосных дорог (`+ Дорога`)
- **Построение в пару кликов:** протяните осевую линию дороги или создайте типовую двух-/четырёхполосную дорогу по шаблону.
- **Настройка геометрии:** регулировка количества параллельных полос и их ширины в метрах.
- **Боковые карманы:** добавление полос расширения слева (для поворота налево) и справа (карманы для остановки МТС или полосы разгона).
- **Разбивка на секции:** инструмент «Разбить секцию» перед перекрёстками позволяет менять количество полос и их назначение без перерисовки всей улицы.
- **Цветовая классификация полос:**
  - 🟢 **Зелёная (Лучшая):** наиболее безопасная полоса для экзаменатора (с неё не выдавят на поворот, нет помех).
  - 🔵 **Синяя (Обычная):** разрешённая стандартная полоса движения.
  - 🔴 **Красная (Избегать):** полоса только на поворот, полоса для маршрутных ТС или ловушка со знаком движения по полосам.
- **Стрелки перестроений:** указатели с подсказками «Перестроиться здесь» между полосами.

### ↶ Траектории манёвров и разворотов (`+ Разворот`)
- Плавные направляющие дуги (кривые Безье) с интерактивным маркером изгиба.
- Настройка типа манёвра:
  - 🟢 *Рекомендуемый*
  - 🟡 *С осторожностью*
  - 🔴 *Запрещённый маневр*
- Отображение стрелок направления движения по траектории.

### 🖍️ Маркер-выделитель (`+ Маркер`)
- Свободное рисование от руки (Freehand drag) или точечное кликанье для выделения опасных участков, слепых зон или сплошных линий.
- Палитра цветов (красный, жёлтый, зелёный, синий, фиолетовый), регулировка толщины линии и опция стрелок направления.

### 📍 Экзаменационные метки (`+ Метка`)
- Набор специализированных пинов с динамическим зум-скейлингом:
  - 🚔 **МРЭО ГИБДД:** начальная точка старта экзамена.
  - ↶ **Место для разворота:** проверенные места для выполнения разворота.
  - 🅿️ **Остановка разрешена:** безопасные карманы и участки обочины.
  - 🚫 **Остановка запрещена:** зоны действия знаков 3.27, выезды из дворов, видимость менее 100 м.
  - ⚠️ **Ловушка инспектора:** неочевидные требования разметки, скрытые знаки, спорные перекрёстки.
  - 🚀 **Скоростной участок / Ограничение:** участки с требованием разгона до максимально разрешённой скорости либо зоны 20/40 км/ч.
- Добавление текстовых заметок и настройка угла обзора (азимута) для быстрого перехода к уличной панораме.

### 📦 Выделение областью (Box Select / «Рамка»)
- Инструмент «Рамка» в панели или быстрое выделение с зажатой клавишей `Shift`.
- Выделите прямоугольником сразу несколько дорог, разворотов, меток и маркеров.
- **Групповое перемещение:** перетаскивайте выбранную группу объектов целиком.
- **Групповое удаление:** быстрое удаление выделенного через баннер действий или клавиши `Delete` / `Backspace`.

### 📷 Уличные панорамы и Яндекс Зеркала
- **Встроенный 360° плеер:** просмотр уличных панорам прямо внутри приложения при клике на перекрёсток.
- **Яндекс Зеркала (Dashcam):** прямая ссылка на фотографии с автомобильных видеорегистраторов для проверки реального состояния дорожных знаков.

### 🎓 Режим самопроверки
- Кнопка **«Скрыть цвета»** временно переводит все полосы в нейтральный серый цвет. Проверьте, помните ли вы безопасную траекторию наизусть, без подсказок.

### 💾 Сохранение и обмен проектами
- Все изменения автоматически сохраняются в браузере (`localStorage`).
- **Экспорт в JSON:** выгрузка всего проекта в один файл для резервного копирования.
- **Импорт из JSON:** мгновенная загрузка маршрута на любом другом компьютере.
- **Демо-маршрут:** встроенный пример экзаменационного маршрута (Смоленск, МРЭО Тихвинка) для быстрого знакомства с возможностями сервиса.

## 🚀 Быстрый старт и локальный запуск

### Требования
- Установленный [Node.js](https://nodejs.org/) версии 18 или выше.
- Пакетный менеджер `npm` (поставляется вместе с Node.js).

### Установка и запуск

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/Homthor/MapHelper.git
   cd MapHelper
   ```

2. **Установите зависимости:**
   ```bash
   npm install
   ```

3. **Запустите сервер разработки:**
   ```bash
   npm run dev
   ```

4. Откройте в браузере адрес, указанный в терминале (обычно `http://localhost:5173`).

### Сборка для публикации (Production)
```bash
npm run build
```
Скомпилированные статические файлы будут находиться в папке `dist/`. Их можно развернуть на любом статическом хостинге (GitHub Pages, Vercel, Netlify, Cloudflare Pages и др.).

## 🔑 Как подключить векторные HD-карты (Ключ Яндекс API)

По умолчанию MapHelper работает в режиме растровых карт. Чтобы включить **векторный движок Яндекс Карты 3.0** с отображением подробной дорожной разметки (полосы, стрелки, островки, стоп-линии) и встроенными панорамами, необходим **бесплатный API-ключ Яндекса**.

### Шаг 1. Регистрация в Кабинете Разработчика
1. Перейдите в [Кабинет Разработчика Яндекс Тех](https://developer.tech.yandex.ru/) и авторизуйтесь под своим Яндекс-аккаунтом.
2. Нажмите кнопку **«Подключить API»** (или выберите добавление нового сервиса).

### Шаг 2. Подключение сервиса «JavaScript API и HTTP Геокодер»
1. В списке сервисов найдите **«JavaScript API и HTTP Геокодер»**.
2. Выберите **Бесплатный тариф** (он включает до **100 запросов в день**, чего с запасом хватает для регулярного личного использования и обучения).
3. Заполните короткую анкету (название проекта, например, `MapHelper`).

### Шаг 3. Настройка HTTP Referer (Обязательно!)
1. В настройках созданного ключа найдите блок **«Ограничение по HTTP Referer»**.
2. Для локального запуска на компьютере добавьте в список значение:
   ```text
   localhost
   ```
   *(Если вы планируете разместить проект на GitHub Pages или своём домене — добавьте также адрес своего сайта, например `homthor.github.io`)*.
3. Сохраните изменения.
4. ⏳ **Важно:** после сохранения в кабинете Яндекса ключ активируется на серверах API в течение **5–15 минут**.

### Шаг 4. Ввод ключа в MapHelper
1. В запущенном приложении MapHelper нажмите на иконку **⚙️ Настройки** в правом верхнем углу тулбара.
2. Вставьте ваш полученный API-ключ в поле ввода.
3. Нажмите **«Сохранить ключ»**.
4. Карта автоматически перезагрузится в векторном режиме Яндекс 3.0 с отображением дорожной разметки.

> [!NOTE]
> **Безопасность и приватность:** Введённый API-ключ сохраняется исключительно в вашем браузере (`localStorage`) и никогда не отправляется на сторонние серверы.

## ⌨️ Горячие клавиши

| Сочетание / Клавиша | Действие |
|---|---|
| `Shift` + зажатие ЛКМ | Быстрое выделение объектов прямоугольной рамкой |
| `Delete` / `Backspace` | Удаление выделенного объекта или группы объектов |
| `Escape` | Сброс выделения / отмена рисования |
| Колёсико мыши | Масштабирование карты (метки плавно скейлятся) |
