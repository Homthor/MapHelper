# MapHelper — Подготовка к экзамену ГИБДД

Интерактивная карта экзаменационных маршрутов и редактор полос движения на базе подробных карт и панорам Яндекса.

## Возможности

- **Карты Яндекса:**
  - **Схема:** Высокодетализированная дорожная разметка (полосы, сплошные, островки) на крупном зуме.
  - **Спутник:** Реальная аэрофотосъёмка асфальта и перекрёстков.
  - **Гибрид:** Совмещение спутниковых снимков с подписями улиц и дорожной сеткой.
- **Уличные панорамы и знаки:**
  - Встроенный просмотр 360° панорам Яндекса в любой точке перекрёстка.
  - Прямой переход к **«Яндекс Зеркалам»** (актуальные снимки с автомобильных видеорегистраторов для проверки свежих дорожных знаков).
  - Поддержка бесплатного ключа Яндекс JavaScript API для встроенного плеера прямо в приложении.
- **Редактор многополосных улиц:**
  - Рисование направления движения и автоматическая генерация параллельных полос.
  - Разделение улиц на секции перед перекрёстками (`Разбить секцию`).
  - Добавление карманов слева (для поворота налево) и справа (разгон/автобусная) с сохранением выравнивания прямых полос.
  - Цветовая маркировка полос:
    - 🟢 **Лучшая** (рекомендуемая безопасная полоса для экзамена)
    - 🔵 **Обычная** (допустимая полоса)
    - 🔴 **Избегать** (полоса только на поворот, автобусная или ловушка)
  - Стрелки перестроений между полосами с подсказками «Перестроиться здесь».
- **Траектории манёвров:**
  - Дуговые стрелки (кривые Безье) для разворотов (↶) и поворотов с интерактивной точкой изгиба.
- **Экзаменационные метки:**
  - МРЭО ГИБДД, места для разворота, разрешённые и запрещённые места остановки, ловушки инспекторов, скоростные участки.
  - Ввод заметок и привязка угла обзора (азимута) для панорамы.
- **Режим самопроверки:**
  - Кнопка **«Скрыть цвета»** временно скрывает зелёные подсказки лучших полос, чтобы вы могли проверить себя по памяти.
- **Локальное сохранение и обмен:**
  - Автосохранение всех правок в `localStorage`.
  - Экспорт и импорт в `.json` для сохранения резервных копий и обмена маршрутами с друзьями или учениками.


## Запуск проекта

```bash
npm install
npm run dev
```

Откройте в браузере: `http://localhost:5173`
